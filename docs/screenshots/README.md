# Скриншоты для README

Положите сюда PNG со следующими именами — README ссылается на них:

- `catalog.png` — главная (каталог), светлая тема.
- `catalog-dark.png` — каталог в тёмной теме (тумблер в хедере).
- `book.png` — страница книги-классики: бейдж «Общественное достояние», кнопки
  «Читать» / «Добавить в библиотеку», блок «Похожие книги».
- `reader.png` — читалка с открытой панелью AI-ассистента.
- `library.png` — личная библиотека: полки + дашборд.
- `settings.png` — настройки профиля: аватар, никнейм, жанры.

Снять можно из запущенного приложения (`npm run dev` + бэкенд), вход —
`reader@example.com` / `password123`.
